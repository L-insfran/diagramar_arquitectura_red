# Manual de usuario — InfraRed PX

Manual orientado al usuario final (paso a paso, lenguaje simple).

## Archivo

- Fuente: [`Manual-Usuario-InfraRed-PX.html`](./Manual-Usuario-InfraRed-PX.html)
- Copia servida por el frontend: `fronted/public/manual/Manual-Usuario-InfraRed-PX.html`
- URL en la app: `/manual/Manual-Usuario-InfraRed-PX.html`
- Acceso en UI: menú del perfil (avatar / nombre) → **Manual de usuario**

## Cómo obtener PDF

1. Abrí el HTML en el navegador.
2. Pulsá **Imprimir / Guardar PDF**.
3. Elegí destino **Guardar como PDF**.

Al actualizar el manual, copiá el HTML también a `fronted/public/manual/` para que coincida con lo que descarga el usuario.
